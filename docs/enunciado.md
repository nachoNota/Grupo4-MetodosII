# Enunciado del proyecto

## Proyecto 4: Integración Numérica y Cálculo de Áreas Irregulares

El cálculo de integrales definidas o volúmenes en dominios geométricos complejos (donde las
integrales analíticas resultan inviables) se resuelve mediante integración numérica. Investigue cómo
se utilizan los métodos de Monte Carlo para resolver una integral definida en 1 dimensión. Comparar
la integral de Monte Carlo con el método de muestreo aleatorio para obtener el área de una figura
irregular. Analice la convergencia a medida que se aumenta el número de simulaciones. Probar
diferentes funciones y figuras irregulares.
